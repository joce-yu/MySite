Project Experience

重點專案成果展示

真實商業案例：自動化金流與 POS 授權延展解決方案。

C# / ASP.NET MVC 金流自動化 POS 授權管理

POS 授權控制與線上金流自動延展系統

在前 4 年的開發工作中，主導規劃此解決方案。成功讓 POS 門市終端軟體與雲端授權主機連動，提供無縫的付款與授權延續體驗。

安全授權邏輯控制

透過 Token 加密與 API 驗證機制，精準管控 POS 軟體有效期限與使用權限。

自動延展 POS 授權

串接線上付款機制，當系統接收到成功的金流回傳（Webhook）後，無須人工介入即刻重新生成並發送新授權碼。

自動化運作流程 (Workflow)

1. POS 終端發起授權驗證 Verify Token
2. 用戶進行線上付款 Payment Success
3. ASP.NET 後端自動更新授權 Auto Renewal
